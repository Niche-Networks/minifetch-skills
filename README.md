# minifetch-skills
Agent skills for Minifetch, a web page extraction & technical-SEO toolkit.

Minifetch is a hosted toolkit of web page extraction primitives. Run them as a full technical SEO audit or call one at a time for a fraction of the price — and a fraction of the LLM tokens. No subscription. Always pay-as-you-go.

[![skills.sh](https://skills.sh/b/Niche-Networks/minifetch-skills)](https://skills.sh/Niche-Networks/minifetch-skills)

## Install

### skills.sh — Claude Code, Codex, Cursor, Gemini CLI, and 50+ other agents
```
npx skills add Niche-Networks/minifetch-skills
```

### Claude Code plugin
Add this repo as a plugin marketplace, then install the bundle:
```
/plugin marketplace add Niche-Networks/minifetch-skills
/plugin install minifetch@minifetch-skills
```

## Skills
- **minifetch-overview** — index & router: what Minifetch can do and which skill to reach for.
- **minifetch-technical-seo-page-audit** — deterministic technical SEO audit of a single page, with documented pass/warn/fail thresholds. No black-box scoring.
- **minifetch-unblock** — allow the Minifetch crawler via robots.txt (for site owners).

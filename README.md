# minifetch-skills
Agents skills for Minifetch web page extraction & SEO toolkit.

Minifetch is a hosted toolkit of web page extraction primitives. Run them as a full technical SEO audit or call one at a time for a fraction of the price — and a fraction of the LLM tokens. No subscription. Always pay-as-you-go.

[![skills.sh](https://skills.sh/b/Niche-Networks/minifetch-skills)](https://skills.sh/Niche-Networks/minifetch-skills)

## Install
```
npx skills add Niche-Networks/minifetch-skills
```
